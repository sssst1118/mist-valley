# 《雾谷仙农录》 / Chronicles of Mist Valley

2D 像素风修仙农场模拟 / 生活模拟 / 角色扮演。PC 单机。

继承一座破败的农场 → 耕种畜牧 → 探索秘境 → 修炼飞升 → 复苏雾谷灵气。

- 技术栈：Godot 4.x + C# (.NET 8) + SQLite + JSON
- 目标平台：Windows / macOS / Linux
