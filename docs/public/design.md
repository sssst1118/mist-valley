## 1. 游戏概述

### 1.1 游戏名称
《雾谷仙农录》（英文：Chronicles of Mist Valley）

### 1.2 核心体验
玩家继承远亲留下的破败农场，来到与世隔绝的雾谷。通过耕种、畜牧、采矿、钓鱼、社交、探索，逐步揭开“大沉寂”的真相。但雾谷并非普通山谷——这里曾是修仙圣地，因“山谷之心”碎裂导致天地灵气枯竭。玩家需重振修仙之道，修复灵脉，在传统与革新、凡俗与仙道之间做出抉择，最终决定雾谷的命运。

### 1.3 目标用户
喜欢《星露谷物语》《牧场物语》《符文工房》的玩家

喜欢《了不起的修仙模拟器》《鬼谷八荒》的修仙游戏玩家

喜欢慢节奏、高自由度、丰富剧情的单机游戏玩家

开源社区贡献者与 Mod 开发者

### 1.4 游戏时长
主线：约 80-120 小时

全收集/全结局/飞升：约 200-300 小时

无限沙盒模式：通关后继续经营

### 1.5 核心特色
完整农场模拟：种植、畜牧、加工、建造、自动化

完整修仙体系：九大境界、灵根、功法、丹药、法宝、灵脉、福地、宗门、渡劫飞升

深度探索：120 层矿洞、多水域钓鱼、野外采集、秘境探索

丰富社交：20+ NPC，10 位可攻略角色，好感度与日程系统，可结为道侣双修

多线剧情：主线三幕、支线任务链、道德选择、多结局

季节与天气：28 天季节，6 种天气，影响玩法与 NPC

开源可扩展：完整 Mod API，支持社区创作

## 2. 世界观与背景

> ⚠️ **2.1 雾谷的过去**、**2.4 主要势力** 含剧透，见 `docs/spoilers/lore.md` §1、§2。

### 2.2 玩家的到来
玩家继承了一位素未谋面的远亲留下的农场。这座农场恰好坐落在一处微型灵脉节点之上。随着玩家开垦土地、种植灵植、修复山谷之心，雾谷的灵气开始复苏。

### 2.3 主线目标
从“修复山谷之心”升级为“复苏雾谷的天地灵气”。玩家需要重振修仙之道，修复灵脉，最终让雾谷重新成为人杰地灵的修仙圣地，或选择另一条道路。

### 3.2 季节系统
每季 28 天，共 4 季（春、夏、秋、冬）

季节更替时：

非温室作物枯萎

地图外观变化（树木、草地、色调）

NPC 日程与对话变化

灵气浓度随季节波动（春 +10%，夏 +5%，秋 +10%，冬 -10%）

季节最后一天有“季节结算”，统计农场产出

## 6. 农场经营系统

### 6.1 土地与种植
耕地：用锄头开垦，只能开垦可耕地

播种：选择种子，播种在耕地上

浇水：每日浇水，雨天自动浇水，洒水器自动浇水，灵雨术自动浇水

生长阶段：每作物 4-6 阶段，每阶段 1-3 天

收获：成熟后收获，部分作物可多次收获

品质：普通、银星、金星、铱星（概率受耕种等级、肥料、灵气浓度影响）

肥料：基础肥料、优质肥料、速生肥料、保湿肥料、豪华肥料

灵植：特殊作物分类，生长周期更长，但可用于炼丹、炼器、烹饪灵食

### 6.3 杂交育种（参考桃源乡）
在工坊中可进行作物杂交

配方：两种作物 + 催化剂 → 新种子

共 400+ 杂交配方，可培育出稀有作物、特殊效果作物、灵植

示例：草莓 + 蓝莓 → 蓝莓草莓（售价 200，可多次收获）

灵植杂交：灵芽草 + 火灵花 → 灵火草（可用于炼制筑基丹）

### 6.4 果树
果树占用 3×3 空间，周围不能有障碍

生长周期：28 天成熟

产出：每季特定果实，品质随树龄提升

果树类型：苹果、樱桃、杏、橙、桃、石榴、香蕉、芒果

灵果树：需灵气浓度达标，产出灵果（可用于炼丹）

## 8. 修仙体系（完整）

### 8.1 境界体系总览
雾谷世界的修仙境界分为三大阶段，共九大境界，每个大境界内部分为初期、中期、后期、大圆满四个小境界。

|---|---|---|---|---|
| 下境界（凡人→筑基） | 炼气期 | 1-13 层 | 80-120 岁 | 第 1 年春季 |

炼气期是唯一的例外，它不按“初期/中期/后期/大圆满”划分，而是按1-13 层逐层递进。炼气一层到三层为初期，四层到六层为中期，七层到九层为后期，十层到十二层为巅峰，十三层为传说中的“炼气大圆满”。绝大多数修士终生止步于炼气期。

### 8.2 每个境界的完整描述
炼气期（1-13 层）
本质：引天地灵气入体，打通经脉，在丹田中积蓄气态灵力。

| 层次 | 能力 | 游戏表现 |
|---|---|---|
| 1-3 层 | 身体略强于凡人，可感知灵气但无法施法 | 解锁“灵气感知”界面，可看到灵田的灵气浓度 |
| 4-6 层 | 可催动低阶法器和符箓，灵气储备可维持短时施法 | 解锁“灵气浇灌”（消耗灵力代替浇水），可装备一阶法器 |
| 7-9 层 | 可施展低阶法术（如轻身术、小回春术），可短时御剑飞行 | 解锁“轻身术”（移动速度 +20%）、“小回春术”（恢复少量体力） |
| 10-12 层 | 灵气储备质变，法术威力大幅提升，可长时间御剑飞行 | 解锁“灵雨术”（范围浇水）、“灵锄术”（范围耕地） |
| 13 层（大圆满） | 传说中的极致层次，丹田灵气满溢，为筑基打下完美根基 | 筑基成功率 +30%，解锁隐藏剧情“炼气十三层” |
寿元：80-120 岁，与长寿凡人无异。修士在炼气期仍会像凡人一样衰老，容貌和身体机能逐渐退化，但可通过丹药维持容貌。

关键限制：

没有神识，仅能靠眼睛视物，无法用神识探查周围。

无法辟谷，需要进食或服用辟谷丹。食用普通食物会在体内堆积杂质，应食用灵食（带有灵气的食物）。

炼气期修为差距三层之内区别不大，三层以上差距显著。炼气七层可以轻松压制炼气三层，炼气九层可以击杀炼气一层。

游戏绑定：

种植灵植需要至少炼气 4 层（灵气浇灌）。

进入秘境需要至少炼气 7 层（可施展基础防护法术）。

招募外门弟子需要至少炼气 5 层（玩家修为足够镇场）。

筑基期（初期/中期/后期/大圆满）
本质：将丹田中的气态灵力压缩为液态，洗髓伐脉，铸就道基，正式脱离凡人范畴。

突破条件：

炼气期修为达到 9 层以上。

服用“筑基丹”（品阶决定成功率，一品筑基丹成功率约 30%，三品约 60%，五品约 90%）。

或使用天材地宝（如“地心乳”、“千年灵参”）辅助突破，成功率额外 +20%。

有雷劫（部分突破方式会引动雷劫，服用筑基丹通常无雷劫，但使用天材地宝强行突破大概率引动雷劫）。

能力跃升：

寿元从 120 岁跃升至 200-250 岁，容貌衰老速度大幅减缓。

产生神识和识海，可用神识探查周围事物、操控物体。神识范围约为 10-30 丈（随修为提升扩大）。

可以御剑飞行，但灵气不足以支撑长时间飞行。

可吸收灵气辟谷，不再需要进食。食用普通食物会堆积杂质，影响修炼，应食用灵食。

身体强度显著上升，即使不动用灵力，与凡人战斗也有极大优势。筑基期修士可轻松击败炼气期修士。

关键限制：

筑基期修士之间修为差距不大，部分个体实力强悍的可以做到越境击杀。

脱胎换骨后应斩断尘世因果，不再入凡世生活，否则易生心魔，不利于未来修行。

游戏绑定：

解锁“神识感知”界面，可探查农场和村庄中的隐藏物品、NPC 心情、灵脉节点。

解锁“御剑飞行”，可在农场和村庄之间快速移动（消耗灵力）。

解锁“灵食烹饪”，普通食物不再提供有效体力恢复，必须使用灵植制作的灵食。

可建造“聚灵阵”（提升农场灵气浓度，加速灵植生长和自身修炼）。

可招募内门弟子（需玩家至少筑基中期）。

金丹期（初期/中期/后期/大圆满）
本质：丹田内的液态灵力凝结为固态金丹，修为发生质变。金丹质量关乎修士未来的潜力，金丹分九品，一品最佳。

突破条件：

筑基期大圆满修为。

需经历雷劫（金丹雷劫，通常为三道到六道，威力视根基而定）。雷劫未过则死。

需服用“结丹灵物”（如“金髓丹”、“龙血草”），不同品阶的结丹灵物影响金丹品质。

天灵根修士结丹瓶颈极小，多灵根需要大量机缘丹药。

能力跃升：

寿元从 250 岁跃升至 500-600 岁。

容貌从此定格，不再衰老，但寿命将近时会继续变老。

可长时间御剑飞行，操控法器。金丹期修士即使没有灵力，纯靠肉体也能一拳击败筑基期以下的修士。普通的武器和火焰无法对金丹期修士的肉身造成伤害。

威压可以直接致凡人重伤。

成为真正的修士，不可再干涉凡人命数，否则会受到反噬。

本命法宝大多在金丹期时选定，本命法宝与修士性命相连，可随修士成长而进化。

金丹九品：

| 品级 | 诞生条件 | 效果 |
|---|---|---|
| 一品金丹 | 天灵根 + 完美筑基 + 顶级结丹灵物 + 雷劫全过 | 修炼速度 +50%，突破元婴概率 +40% |
| 二品金丹 | 天灵根或变异灵根 + 优良筑基 + 高级结丹灵物 | 修炼速度 +35%，突破元婴概率 +30% |
| 三品金丹 | 双灵根 + 良好筑基 + 中级结丹灵物 | 修炼速度 +25%，突破元婴概率 +20% |
| 四品金丹 | 双灵根或三灵根 + 正常筑基 + 中级结丹灵物 | 修炼速度 +15%，突破元婴概率 +10% |
| 五品金丹 | 三灵根 + 正常筑基 + 基础结丹灵物 | 修炼速度 +5%，突破元婴概率 +5% |
| 六品金丹 | 三灵根或四灵根 + 勉强筑基 + 基础结丹灵物 | 修炼速度无加成，突破元婴概率 -10% |
| 七品金丹 | 四灵根 + 勉强筑基 + 劣质结丹灵物 | 修炼速度 -10%，突破元婴概率 -20% |
| 八品金丹 | 伪灵根 + 强行筑基 + 无结丹灵物 | 修炼速度 -20%，突破元婴概率 -40% |
| 九品金丹 | 伪灵根 + 强行筑基 + 丹药堆砌 | 修炼速度 -30%，突破元婴概率 -60%（几乎无望） |
游戏绑定：

解锁“金丹视界”，可看到灵脉走向、灵气浓度分布、隐藏的灵物。

解锁“本命法宝”系统，可选择一件法宝作为本命法宝进行培养。

可建造“护山大阵”（保护农场免受妖兽和敌人侵袭）。

可招募亲传弟子（需玩家至少金丹中期）。

灵植可升级为“金丹灵植”（生长周期更长，但产出可用于炼制金丹期丹药）。

元婴期（初期/中期/后期/大圆满）
本质：金丹破碎，孕育元婴。元婴位于丹田，与修士性命相连。元婴可离体，神识大幅扩张。

突破条件：

金丹期大圆满修为。

需经历元婴雷劫（通常为六道到九道）。

需服用“化婴丹”或使用“元婴果”等天材地宝。

金丹品质影响突破概率：一品金丹突破概率约 70%，九品金丹几乎为零。

能力跃升：

寿元从 600 岁跃升至 800-1000 岁。在凡界已属于一方大佬。

元婴可离体活动，离体元婴可瞬移。元婴离体时，肉身处于无防备状态。

神识大幅扩张，可覆盖方圆数里。

肉身极其强悍，纵使无法使用灵力，重伤濒死，凡人也无法对其造成伤害。完全释放威压时，离得近的凡人会直接化为血雾，弱一些的金丹修士会被压制动弹不得。

元婴期也是化形期，不论人修还是妖修，都可以化为人形或重塑躯体，改变容貌、体型。重塑筋脉和骨肉，但骨龄和资质不能改变。

元婴期后，修为之间的差距和压制加大，很难再出现跨大境界打平手的情况，实力差距巨大。

游戏绑定：

解锁“元婴离体”，玩家可操控元婴在农场和村庄中自由探索（元婴状态下无法战斗，但可穿过障碍物、进入隐藏空间）。

解锁“化形术”，可改变玩家外观（包括发色、瞳色、体型）。

农场可升级为“洞天福地”，灵气浓度大幅提升，灵植生长速度翻倍。

可建造“藏经阁”，招募的弟子可在此学习功法。

可进入高阶秘境（元婴期及以上方可进入）。

化神期（初期/中期/后期/大圆满）
本质：元婴蜕变，肉身与元神合一。神魂可覆盖千里。

突破条件：

元婴期大圆满修为。

需经历化神雷劫（九道雷劫，威力极大）。

需在特定地点突破（如“灵脉交汇处”、“上古洞府”），且需在特定时辰（如“子时”或“午时”）。

需服用“化神丹”或“元神果”。

能力跃升：

寿元从 1000 岁跃升至 1500-2000 岁。凡界顶尖战力。

可短时间撕裂空间，进行空间穿梭。

掌握“元力领域”，在领域内可压制敌人修为。

可破解元婴期修士的瞬移。

游戏绑定：

解锁“空间穿梭”，可在已解锁的地图之间瞬间移动（消耗大量灵力）。

解锁“元力领域”，在农场中可展开领域，范围内灵植瞬间成熟、动物产出品质提升。

可建造“传送阵”，连接雾谷各区域。

可进入顶级秘境（化神期及以上方可进入）。

可开启“飞升之路”主线终局任务。

炼虚期（初期/中期/后期/大圆满）
本质：参悟空间法则，肉身逐步向法则转化。

突破条件：

化神期大圆满修为。

需在“空间裂缝”中历练，或使用“虚空石”辅助突破。

需经历虚空劫（空间风暴，非雷劫）。

能力跃升：

寿元从 2000 岁跃升至 3000 岁。

体内元婴化为元神，返虚出本体，可化为分身或众多分身。

初掌天地法则，可调动周围空间之力。

游戏绑定：

解锁“分身术”，可同时进行多项活动（如一个分身种田，一个分身采矿）。

可建造“洞天”，农场成为一个独立的小世界，不受外界季节和天气影响。

可进入虚空秘境（炼虚期及以上方可进入）。

合体期（初期/中期/后期/大圆满）
本质：肉身、元婴、元神三者合一，天人相应。

突破条件：

炼虚期大圆满修为。

需经历合体天劫。

需找到“合道之地”（天地灵气汇聚之处）。

能力跃升：

寿元从 3000 岁跃升至 4000 岁。

法力暴涨，可调动天地之力。

神魂与肉身完全合一，不再有元婴离体的弱点。

游戏绑定：

解锁“天地之力”，可改变农场局部气候（如制造小雨、晴天）。

可建造“天地祭坛”，用于渡劫和飞升仪式。

灵植可升级为“合道灵植”（产出可用于飞升丹药）。

大乘期（初期/中期/后期/大圆满）
本质：凡界修行终点，法则感悟近乎圆满，只待天劫。

突破条件：

合体期大圆满修为。

需积累足够“道韵”（通过完成游戏中的各种成就和收集获得）。

需经历大乘天劫（九道天劫，威力足以毁灭一方小世界）。

能力跃升：

寿元从 4000 岁跃升至 5000 岁以上。

熟练使用或自创神通，法力肉身已具备飞升上界的条件。

可调动天地法则，一念之间改变地貌。

游戏绑定：

解锁“神通自创”，玩家可组合已有法术创造新神通。

可建造“飞升台”，准备飞升仪式。

所有灵植和动物自动升级为最高品质。

渡劫期
本质：引九天雷劫，渡过则飞升仙界；失败则身死，或舍弃肉身成为散仙。

渡劫条件：

大乘期大圆满修为。

需集齐“飞升三宝”（飞升丹、护劫法宝、引雷阵）。

需在“飞升台”上进行渡劫仪式。

渡劫过程：渡劫天劫共有九道劫难，依次为：

天风劫：狂风化作白刃，攻击身体表面及五脏六腑。

天火劫：火焰漩涡在体表与体内烧灼。

天水劫：雨滴化作细针，冲击在渡劫者身上。

业火劫：业火是一个人的恶所产生的，自身气运会减轻业火。业火伤害身体，折磨灵魂。

色劫：感觉无比真切而无法摆脱，只能忍受。

心魔劫：引动修炼者的脆弱点，影响渡劫者的心智，考验意志。

轮回劫：不断轮回，边做不同身份，考验道心和人性。

天灵劫：雾气透过身体，带着恐怖的冲击波，直接冲击渡劫者灵魂深处。越厉害的人，难度越大。

雷劫：数量从三道到九道，渡劫者实力越强，雷劫威力越大，所引动雷劫的数量也就越多。最强威力的雷劫为太金雷劫。

渡劫结果：

全部渡过：飞升仙界，触发“飞升结局”。

渡劫失败但保住性命：修为跌落至大乘期初期，需重新积累。

舍弃肉身：成为散仙，寿元悠长（约 10000 年），但永难飞升。触发“散仙结局”。

身死道消：游戏结束（可读档重来）。

游戏绑定：

渡劫期是游戏的终局内容，触发后进入“飞升篇章”。

渡劫过程中有多个互动环节（如选择使用护劫法宝的时机、选择服用飞升丹的时机）。

渡劫结果影响最终结局。

### 8.4 突破与渡劫机制
突破瓶颈
| 境界突破 | 瓶颈难度 | 突破条件 |
|---|---|---|
| 炼气→筑基 | 中 | 筑基丹/天材地宝，可能引动雷劫 |
| 筑基→金丹 | 高 | 结丹灵物，必引雷劫（3-6 道） |
| 金丹→元婴 | 极高 | 化婴丹，必引雷劫（6-9 道） |
| 元婴→化神 | 极高 | 化神丹 + 特定地点 + 特定时辰，必引雷劫（9 道） |
| 化神→炼虚 | 极高 | 虚空石 + 空间裂缝历练，虚空劫 |
| 炼虚→合体 | 极高 | 合道之地 + 合体天劫 |
| 合体→大乘 | 极高 | 道韵积累 + 大乘天劫 |
| 大乘→渡劫 | 最高 | 飞升三宝 + 九道天劫 |
渡劫机制
雷劫：

雷劫数量：3-9 道，修为越强雷劫越多，威力越大。

渡劫方式：玩家需在渡劫前准备“护劫法宝”和“渡劫丹”。渡劫过程中有 QTE（快速反应事件），玩家需在雷劫落下的瞬间选择“硬抗”、“闪避”或“用法宝抵挡”。

渡劫失败：轻则重伤（修为跌落），重则身死道消。

非雷劫（渡劫期九劫）：

天风劫、天火劫、天水劫：环境伤害，需使用对应属性的防护法宝。

业火劫：伤害与玩家的“业力值”相关，业力越低伤害越小。业力值由玩家在游戏中的道德选择决定。

色劫、心魔劫、轮回劫：精神考验，玩家需在对话选项中选择正确回答。道心越坚定，越容易通过。

天灵劫：灵魂冲击，需使用“护魂法宝”。

心魔系统
心魔触发条件：

突破大境界时概率触发。

渡劫时必定触发（心魔劫）。

玩家做出违背道心的选择时概率触发。

心魔表现：

心魔会以玩家的“阴暗面”出现，变成玩家最害怕的东西。

心魔会引动玩家在游戏中的“遗憾”——如未完成的承诺、伤害过的 NPC、放弃的支线任务。

心魔战中，玩家需在对话选项中选择“面对”、“逃避”或“化解”。选择“面对”有概率直接战胜心魔（道心越坚定概率越高）；选择“逃避”则心魔暂时退去但会在下次突破时更强；选择“化解”需要完成特定条件（如向 NPC 道歉、完成未竟之事）。

道心值：

道心值 0-100，初始 50。

做出符合道心的选择 +5，做出违背道心的选择 -10。

道心值 ≥80：渡劫时心魔劫难度大幅降低。

道心值 ≤20：随时可能被心魔入侵，修炼速度 -50%。

## 21. 技术架构
### 21.1 目录结构
```
res://
├── core/        # 时间、天气、存档、事件总线、输入
├── systems/     # 种植、畜牧、采矿、钓鱼、社交、经济、建造、技能、修仙
├── world/       # 农场、城镇、矿洞、森林、海岸、秘境
├── entities/    # 玩家、NPC、动物、怪物、物品
├── ui/          # HUD、菜单、对话框
├── data/        # JSON/SQLite 数据表
├── mods/        # Mod 加载器
└── assets/      # 美术、音频
```

### 21.2 核心原则
- 模块化、事件总线、数据驱动、组件化、依赖注入
- 存档带版本号，支持迁移
- 公开 Mod API，支持数据覆盖与脚本扩展
- 核心逻辑纯 C#，可单元测试
